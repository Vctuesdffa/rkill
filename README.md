Сапёр (Minesweeper)

                                           Описание проекта

Сапёр — это классическая логическая игра, в которой игрок должен открыть все безопасные клетки на игровом поле, не попав на мины.

Игра помогает развивать логическое мышление, внимательность и умение анализировать ситуацию.

Правила игры
1. Игрок открывает клетки на игровом поле.
2. Если клетка содержит мину, игра заканчивается поражением.
3. Если клетка безопасна, на ней может появиться число, показывающее количество мин в соседних клетках.
4. Используя числа, игрок определяет расположение мин.
5. Игрок побеждает, если открывает все безопасные клетки.

Основные возможности
* Игровое поле с безопасными клетками и минами.
* Проверка открываемых клеток.
* Отображение количества мин рядом с клеткой.
* Возможность выиграть или проиграть.
* Простой и понятный игровой процесс.

Используемые технологии

 HTML — структура игры.
 CSS — оформление игрового интерфейса.
 JavaScript — игровая логика.

управление 
управление осуществляется на левую кнопку мыши

запуск игры

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта.
3. Найдите файл `index.html`.
4. Откройте его в браузере.
